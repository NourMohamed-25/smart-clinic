# Smart Clinic 🏥

## Project Overview

**Smart Clinic** is a solution to a common problem in urgent medical appointments. When a patient's condition may be serious, they sometimes have to wait for other patients who booked appointments before them. This delay can increase the risk if the patient does not receive medical attention quickly.

To address this problem, I created **Smart Clinic**, a simple patient priority and appointment system using the programming concepts and tools I learned through the **CS50 Introduction to Computer Science course**.

The project is built around a simple website where the patient enters:

* First name only (as a prototype)
* Age
* Initial symptoms
* The time period during which they are available for an appointment

## How the System Works

### 1. C++ — Patient Priority

The C++ part of the project calculates an **urgency score** for each patient.

The program checks the patient's age. If the patient is:

* Under 5 years old
* Over 65 years old

additional points are added to the urgency score.

The program also checks for important symptoms that may require urgent medical attention, such as:

* Sudden loss of consciousness
* Chest pain
* Skin rash
* High fever
* Shortness of breath
* Sudden weakness

When the patient enters their symptoms, the program checks whether they match any of the emergency symptoms defined in the system and calculates the patient's urgency score accordingly.

If no emergency symptoms are detected, the patient receives a lower default score.

After calculating the scores, **Selection Sort** is used to arrange the patients from the highest urgency score to the lowest.

### 2. Python & Flask — Data Processing and Appointments

The Python part of the project uses **Flask** to connect the website with the C++ program.

When a patient submits their information through the website, Python:

1. Receives the patient's data.
2. Stores the data in a file called `patients.txt`.
3. Reads the patient's available time period.
4. Uses a list of appointment times divided into **30-minute intervals**.
5. Runs the C++ program after the required number of patients have been entered.
6. Reads the results generated by the C++ program.
7. Assigns an available appointment time to each patient.
8. Displays the final results on a separate results page.

The C++ program stores the calculated patient priorities in `result.txt`, which is then read by Python.

## 3. HTML & CSS — User Interface

The website interface was created using **HTML** and **CSS**.

HTML is used to create the patient data form and the results page, while CSS is used to make the website organized, readable, and visually consistent.

The final results page displays:

| Patient      | Priority Score | Appointment      |
| ------------ | -------------: | ---------------- |
| Patient Name |  Urgency Score | Appointment Time |

## Technologies Used

* **C++** — Urgency score calculation and patient sorting
* **Python** — Data processing and application logic
* **Flask** — Connecting the website with the backend
* **HTML** — Website structure
* **CSS** — Website styling
* **Text Files** — Storing and transferring data between the C++ and Python parts
## How to Run

To run the Smart Clinic project:

1. Make sure **Python 3** is installed.
2. Install Flask:

```bash
pip install flask
```

3. Make sure **MSYS2 UCRT64** is installed with a C++ compiler.
4. Open the project folder in **MSYS2 UCRT64**.
5. Compile the C++ program:

```bash
g++ final.cpp -o final.exe
```

6. Run the Flask application using the Python executable installed on your computer:

```bash
python final.py
```

If the `python` command is not recognized, use the full path to the Python executable installed on your computer:

```text
"C:\Path\To\Python\python.exe" final.py
```

7. Open the local Flask address shown in the terminal, usually:

```text
http://127.0.0.1:5000
```

For the current prototype, enter data for **5 patients**. After the fifth patient is submitted, the C++ program processes the patient data, calculates the urgency scores, sorts the patients by priority, and generates the results displayed on the results page.

The patient limit can be increased later by modifying the patient limit in the code.

## Project Goal

The main goal of Smart Clinic is to demonstrate how basic programming concepts can be combined to create a practical system.

The project combines **patient priority evaluation** with **appointment scheduling** so that patients with more urgent conditions can be prioritized while still considering the time period during which each patient is available.

> **Note:** Smart Clinic is an educational CS50 project and is not intended to replace professional medical diagnosis or emergency medical services.
